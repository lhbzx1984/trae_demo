# 贪吃蛇游戏

## 项目介绍
这是一个为初中生设计的简单贪吃蛇游戏，使用HTML5 Canvas和JavaScript实现。游戏界面简洁直观，操作容易上手。

## 项目功能

### 1. 游戏开始
- 点击"开始游戏"按钮启动游戏
- 蛇从初始位置和长度开始移动
- 随机生成第一个食物

### 2. 游戏进行中
- 使用方向键（↑↓←→）控制蛇的移动方向
- 蛇头碰到食物时身体增长，得分增加
- 食物被吃掉后随机生成新的食物
- 游戏难度随分数提升（蛇速逐渐加快）

### 3. 游戏结束
- 蛇头碰到墙壁时游戏结束
- 蛇头碰到自身时游戏结束
- 显示最终得分和"游戏结束"提示
- 提供"重新开始"选项

### 4. 游戏暂停
- 按空格键暂停/继续游戏
- 暂停时显示半透明遮罩和提示文字
- 可继续游戏或返回主菜单

### 5. 游戏重新开始
- 游戏结束后可重新开始游戏
- 重置蛇的位置、长度和方向
- 重置得分和游戏速度
- 重新生成食物

### 6. 游戏设置
- **难度选择**：简单、中等、困难三个等级
- **速度调节**：可调整蛇的移动速度（1-10级）
- **音效开关**：开启/关闭游戏音效
- **网格显示**：显示/隐藏背景网格辅助线

## 使用方法
1. 打开 `index.html` 文件即可运行游戏
2. 使用键盘方向键控制蛇的移动
3. 按空格键暂停/继续游戏
4. 通过设置面板调整游戏难度和偏好

## 技术实现
- HTML5 Canvas 绘制游戏界面
- JavaScript ES6 实现游戏逻辑
- CSS3 实现响应式布局和动画效果
- 模块化设计，代码结构清晰
